01 How config works

The one mental model that explains every "why is my setting ignored?" — two files, and the GUI always wins.

Your layer — hand-edited

~/.config/noctalia/*.toml

Every *.toml here is read (alphabetical merge), non-recursive. Split freely: bar.toml, theme.toml… Recommended for dotfiles.

GUI layer — app-managed wins

~/.local/state/noctalia/settings.toml

Written by the Settings UI, setup wizard, and IPC. Loads last, so it overrides your hand-edited files key-for-key.

Load order (last wins)

  • Built-in defaults
  • Your ~/.config/noctalia/*.toml — each file's [include] contents first, then its own keys
  • GUI overrides settings.toml — this is why a hand-edited key can look ignored. Inspect that file if a setting won't stick.

Splitting & includes

[include]
files = [
  "widgets/",                   # every *.toml in dir, sorted
  "bars/top.toml",             # single file
  "~/.config/shared/base.toml" # ~, $VAR expanded
]
# autoload = false  → load ONLY this file (profile switching)

Includes merge as a base; the including file's own keys win. [include] is honored in your files only — never in settings.toml.

CLI

CommandDoes
noctalia config exportMerged user config → stdout (use this for dotfiles)
noctalia config export fullFull effective config incl. every default — the real schema
noctalia config validateTOML syntax + unknown/obsolete keys + bad enums

On your machine

Right now v5 runs purely from settings.toml (the setup wizard wrote defaults). ~/.config/noctalia/ is empty. To version-control your setup in dotfiles, build it there as *.toml and let it be the base layer.

02 Theme & palette

The [theme] table picks a mode and a color source. Custom palettes use the same JSON format as v4 — Peche drops straight in.

[theme]
mode              = "dark"        # dark | light | auto (auto follows [location] sun times)
source            = "custom"      # builtin | wallpaper | community | custom
custom_palette    = "Peche"       # filename WITHOUT .json in palettes/
builtin           = "Noctalia"    # when source = builtin
community_palette = "Oxocarbon"   # when source = community
wallpaper_scheme  = "m3-content"  # when source = wallpaper

Recreate Peche

  1. Copy your scheme to ~/.config/noctalia/palettes/Peche.json
  2. Set source="custom", custom_palette="Peche"
  3. Or live: noctalia msg color-scheme-set custom Peche

Palette JSON shape

Top-level "dark" + optional "light". 16 role keys each (mPrimary, mSurface, mOutline, mHover…) plus a terminal object (normal/bright ANSI + fg/bg/cursor/selection). Hex #RGB…#RRGGBBAA.

03 Bar

Bars are named tables under [bar.<name>]. Each spawns on every monitor; per-monitor overrides refine it. Widgets go in three lanes: start / center / end.

[bar.default]
position   = "top"         # top | bottom | left | right
thickness  = 34
background_opacity = 0.35
border     = "outline"     # role or #RRGGBB
margin_edge = 2            # >0 floats the bar (your old "floating" look)
radius     = 12
scale      = 1.0          # bar content scale (fonts/icons)
start  = ["launcher", "workspaces", "active_window"]
center = ["media", "clock", "sysmon"]
end    = ["tray", "notifications", "volume", "brightness", "control-center", "session"]

[bar.default.monitor."DP-1"]    # per-monitor override; first match wins
position = "top"            # match by connector OR description substring
# enabled = false  → remove this bar from that output

04 Bar widgets

A lane entry is a widget name. Define [widget.<name>] with a type to configure it (or to run two of the same kind); a bare name with no table just uses that name as the type with defaults.

[widget.clock]
type   = "clock"
format = "{:%H:%M  %a, %d %b}"   # strftime tokens; \n for two lines

[widget.sysmon]              # one instance per stat — add several
type = "sysmon"
stat = "cpu_temp"            # see stat table below

RTX 5060 note

GPU stats exist as gpu_temp and gpu_vram, both via the NVML fallback on your proprietary driver. There is no gpu-usage% stat. Sampling cadence is global under [system.monitor], not per-widget.

05 Dock

A standalone app dock — disabled by default. Pinned apps match by desktop-entry stem, then WM class, then name.

[dock]
enabled  = true
position = "bottom"
monitors = ["HDMI-A-1", "DP-1"]   # empty = all outputs
pinned   = ["firefox", "kitty", "org.kde.dolphin", "vivaldi-stable"]
auto_hide = false
launcher_position = "none"          # none | start | end
magnification = true               # macOS-style pointer magnify
show_running = true

Other keys: icon_size (48), background_opacity (0.88), show_dots, show_instance_count, active_scale/inactive_scale, radius, margin_edge, reserve_space.

08 Desktop widgets

Free-floating surfaces placed by pixel coordinate per output. Best built with the visual editor, then exported to TOML.

[desktop_widgets.widget.clock_main]
type   = "clock"       # button clock label sysmon weather media_player sticker
output = "DP-1"
cx = 1200            # center X/Y in logical px
cy = 280
[desktop_widgets.widget.clock_main.settings]
clock_style = "digital"
format = "{:%H:%M}"

Editor

noctalia msg desktop-widgets-toggle-edit — drag = move, ring = rotate, corner = resize, G = snap grid, Delete = remove. Also fancy_audio_visualizer, audio_visualizer. Then Settings → Export → Merged User Config to promote to declarative TOML.

09 Services

Each is its own top-level table. All small; the essentials:

[weather]

enabled, unit (metric/imperial), refresh_minutes (30). Needs [location] (set auto_locate or address). Open-Meteo, 6-day forecast.

[notification]

enable_daemon, position (top_right…), layer, scale, monitors, offset_x/y. Filters: [notification.filter.<name>]. DND is IPC-only.

[brightness]

enable_ddcutil for external DDC/CI, minimum_brightness, sync_all_monitors. Per-display: [brightness.monitor.<name>] backend = auto/backlight/ddcutil/none.

[nightlight]

enabled, temperature_day (6500), temperature_night (4000), force. Schedule derived from [location] sun times.

[audio]

enable_overdrive (→150%), enable_sounds, sound_volume, custom volume_change_sound / notification_sound.

[idle] + [idle.behavior.*]

Actions lock / screen_off / suspend / lock_and_suspend / command, each with timeout. pre_action_fade_seconds dims first.

11 App theming (templates)

Noctalia writes your palette into other apps' config on every theme change. Opt in by id under [theme.templates].

[theme.templates]
enable_builtin_templates   = true
builtin_ids = ["kitty", "gtk3", "gtk4", "qt", "kcolorscheme", "btop"]
enable_community_templates = true
community_ids = ["zen-browser", "pywalfox"]

Your old v4 templates — all present in v5

Built-in: kitty · gtk3 · gtk4 · qt · kcolorscheme · btop · alacritty · foot · ghostty · starship · hyprland · emacs. Community: zen-browser · pywalfox · vscode · neovim · discord · spicetify · rofi · fuzzel. List live with noctalia theme --list-templates.

User templates: [theme.templates.user.<id>] with input_path, output_path, post_hook. Engine has 48 Material tokens + terminal colors, filters, and loops.

12 Plugins

Directories with a plugin.toml + Luau scripts. Two default git sources; "installed ≠ enabled".

noctalia msg plugins list
noctalia msg plugins enable  noctalia/screen_recorder
noctalia msg plugins disable noctalia/screen_recorder
noctalia msg plugins update  official
noctalia msg plugins source add my-dev path ~/dev/my-plugins

Sources: official noctalia-dev/official-plugins, community noctalia-dev/community-plugins. Send an event: noctalia msg plugin <author/plugin:entry> <target> <event>. Declare in config under [plugins] / [[plugins.source]].

13 Hyprland integration

What the docs recommend for the best experience — matched to your Lua-native config (~/.config/hypr/hyprland.lua). Window class is dev.noctalia.Noctalia.

-- autostart
hl.on("hyprland.start", function() hl.exec_cmd("noctalia") end)

-- blur + no-fight anims on Noctalia surfaces
hl.layer_rule({
  name = "noctalia",
  match = { namespace = "^noctalia-(bar-.+|notification|dock|panel|attached-panel|osd)$" },
  no_anim = true, blur = true, blur_popups = true, ignore_alpha = 0.5,
})

-- float the settings window
hl.window_rule({ match = { class = "dev.noctalia.Noctalia" }, float = true, size = { 1080, 920 } })

Your autostart.lua and keybinds.lua are already migrated to these forms. The docs make no mention of uwsm for Noctalia itself.
